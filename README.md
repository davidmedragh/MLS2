# MLS2 — StreamWave Churn Analysis

Notebook d'analyse exploratoire du churn client de StreamWave.

## Démarrage

Ouvrir `MLS_DMEDA.ipynb` dans Jupyter ou VS Code et sélectionner le noyau Python 3.12 (uv: MLS2). La première cellule initialise `uv`, synchronise les dépendances depuis `pyproject.toml` et prépare l'environnement du notebook.

Les jeux de données sont dans `dataset/`.
